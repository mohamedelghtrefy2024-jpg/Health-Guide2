## 📊 الحسابات:

### BMR (معدل الأيض الأساسي):
```
الرجال: 10 × وزن + 6.25 × طول - 5 × عمر + 5
النساء: 10 × وزن + 6.25 × طول - 5 × عمر - 161
```

### TDEE (حرق يومي كلي):
```
TDEE = BMR × معامل النشاط
(1.2 - 1.9 حسب النشاط)
```

### الهدف اليومي:
```
للتخسيس: TDEE - عجز (200-1000)
للتثبيت: TDEE
للتضخيم: TDEE + فائض (100-400)
```
